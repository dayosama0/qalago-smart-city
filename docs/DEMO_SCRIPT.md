# Демонстрация QalaGo

Сценарий рассчитан примерно на две минуты. Записывайте только реально работающий экземпляр приложения. До записи откройте `streamlit run app.py`, убедитесь, что SQLite-снимок доступен, и не показывайте `.env`, secrets или терминал с ключами. Видео и слайды не загружены автоматически.

Если OpenAI не настроен, показывайте режим «Без LLM». Фактический статус публичного хостинга берите из итогового отчёта, не из этого сценария.

## План презентации: 7 слайдов, 5–7 минут

1. **Проблема (45 сек).** У гостя Астаны ограничено время; погода, расстояние и неполнота данных мешают выбрать ближайшее занятие. Не приводите несуществующие метрики пользователей.
2. **Продукт (45 сек).** Ручная точка старта, бюджет времени и интересы → до трёх карточек. Прямые совпадения отделены от запасных категорий. Покажите реальный экран и четыре быстрых сценария.
3. **Данные и доверие (50 сек).** OSM → очищенные публичные записи → проверка → SQLite. Покрытие ограничено малыми областями, не всей Астаной. Описания и уточнённые часы имеют отдельные публичные доказательства; это кабинетная проверка, не посещение места.
4. **Структурированный RAG (50 сек).** SQL и геометрия → время посещения, доступ и строгие свойства → климат → необязательный LLM → проверка. Поддерживаемый недельный график сопоставляется со всем визитом; неподдерживаемые правила остаются `unknown`. Живой LLM-режим показывайте только после реального подтверждённого вызова.
5. **Climate Shield Comparison (60 сек).** Кнопка запускает оба расчёта с одинаковыми часами и погодой без LLM. Оценка относится к первому показанному варианту. Если на одной стороне результата нет, разница не вычисляется; если порядок одинаков, сокращение не приписывается.
6. **Честные пограничные случаи (60 сек).** Строгая розетка, часы OSM, вылет из аэропорта, нет ключа, недоступная погода. Укажите фактические результаты тестов из текущего прогона.
7. **Запуск и развитие (45 сек).** Streamlit Community Cloud, отдельные secrets, автоматический перезапуск после push в выбранную ветку. Показывайте публичный URL только если он реально проверен. Дальнейшая официальная интеграция 2ГИС и проверенная дорожная сеть — возможные направления после MVP, не готовые возможности.

## Что подготовить вручную

- Записать экран и при необходимости загрузить видео со своего аккаунта.
- Снять реальные карточки и sidebar после удачного запуска, избегая приватных координат и секретов.
- Сверить фактические наблюдения по пяти сценариям в `docs/TEST_SCENARIOS.md`; для мобильной версии использовать реальные проверки ширины и отсутствия горизонтального скролла из `docs/VERIFICATION.md`.
- Если Streamlit Cloud требует входа: войти своим GitHub-аккаунтом, выбрать репозиторий, `main` и `app.py`, развернуть и открыть приложение. Подробные шаги — в README.
