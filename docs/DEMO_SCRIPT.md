# QalaGo — план записи на 120 секунд

Это сценарий будущей записи, а не подтверждение создания или загрузки видео. Основной вариант — **чистая локальная копия проверяемой ревизии `a453712`**, запущенная командой `python -m streamlit run app.py`, с шаблонными объяснениями. После проверки, объединения PR и отдельной проверки нового приложения из `main` можно записать тот же поток на новом публичном экземпляре, указав его фактические URL и ревизию.

Текущая [публичная preview-версия](https://applago-smart-city-dwywv3hxsdtjbdhhj8qien.streamlit.app/) проверялась для ветки PR №1 на `348b6a4`; точный Cloud build SHA не раскрыт. **Новая внешняя навигация из `a453712` туда не развёрнута.** При записи локального приложения подпишите кадр «Локальная проверяемая версия a453712»; показ публичной ссылки не означает, что все записанные новые возможности уже доступны по ней. Переход к `main` — отдельная процедура из [release checklist](RELEASE_CHECKLIST.md).

## Подготовка вне записи

- Используйте отдельную копию кода без ключа во всех источниках конфигурации: локальном или родительском `.env`, окружении, локальных и глобальных Streamlit secrets. Это важно и для вложенных worktree: dotenv может искать файл выше каталога проекта. До записи убедитесь в шаблонном режиме. Откройте только приложение; секреты и приватные координаты не должны попадать в кадр. Для демонстрации достаточно публичных ориентиров.
- В основной вкладке подготовьте стартовый экран. Во второй локальной вкладке заранее задайте **Байтерек → 60 минут → «Необычное» → запрос «необычное занятие ночью» → ясная симуляция → часы 19.10.2026, 23:00, Asia/Almaty**. Флаг вылета и строгая розетка выключены, Shield включён. На записи нажмите подбор заново: подготовленные параметры не заменяют реальный расчёт.
- Проверьте доступность снимка: **199 реальных POI в четырёх демо-зонах**, а не полное покрытие Астаны. В «Прозрачности данных» доступны свежесть, 81 расписание, шесть описаний и атрибуция OSM. Сверяйте числа с фактическим экраном.
- Открывайте Google Maps только для публичного старта. Для собственных координат интерфейс требует отдельного разрешения на передачу Google Maps; такая демонстрация с приватной точкой здесь не нужна.
- Последний реальный OpenAI-запрос имеет статус **`not_verified`**, HTTP **429 / `credit_balance_exhausted`**: это блокировка по балансу API, а не установленная ошибка реализации. Шаблонный режим работает. На записи не делайте новый платный запрос и не представляйте его как успешную генерацию. [Фактический безопасный отчёт](live-llm-verification.json).

## Финальный кадр и подписи к метрикам

На финальном кадре можно кратко разместить:

- **Показано:** локальная проверяемая версия `a453712` либо отдельно проверенная новая `main` с фактическим SHA и URL.
- **Существующая публичная preview:** PR №1, `348b6a4`; новая навигация пока локальная.
- **Автоматическая оценка:** 15 авторских синтетических запросов к реальным POI; категорийный прокси **9/15**, расчётный бюджет соблюдён у **39/39** карточек. Это не оценка человеческой релевантности; формы двух независимых оценщиков пока пусты. [Чистая ревизия, результаты и ограничения](../evaluation/release-a453712/report.md).
- **LLM:** `not_verified`, 429 / `credit_balance_exhausted`; шаблонный режим доступен. Успешная живая генерация не показана.

В двухминутном ролике не требуется зачитывать все цифры. Если они есть в титрах или слайдах, сохраняйте подписи «категорийный прокси» и «расчётный бюджет». Нулевое число несовпадений полей снимка не доказывает отсутствие всех неподтверждённых утверждений.

## Семь слайдов для выступления на 5–7 минут

1. **Проблема · 45 с.** Свободное время, погода и неполнота городских данных мешают выбрать прогулку. Без выдуманных пользовательских метрик.
2. **Пользовательский поток · 45 с.** Старт, время, интересы и четыре быстрых сценария. Совпадения и запасные категории разделены; подпишите показанную ревизию.
3. **Данные · 50 с.** 199 POI в четырёх областях OSM; SQLite, исходные публичные снимки, ODbL и шесть описаний с доказательствами. Это кабинетное обогащение, не посещение мест.
4. **Извлечение и необязательный LLM · 50 с.** SQL/геометрия → время и строгие ограничения → погода и ранжирование → необязательный выбор пояснений LLM → валидация. Поддерживаемые часы проверяют весь визит; сложные правила остаются неизвестными. LLM ограничен исходными фразами и сейчас не подтверждён живым успешным вызовом.
5. **Climate Shield · 60 с.** Один запрос OFF/ON. Показать два разных варианта и оценки 35,0 / 0,7; явно указать неопределённость `likely_indoor`. Не выводить из этого доказанную безопасность или универсальное процентное улучшение.
6. **Проверки и ограничения · 60 с.** Ночь, вылет, строгая розетка, fallback; актуальный результат тестов из финального отчёта. Автоматические 15 авторских случаев отделить от ещё не выполненной человеческой оценки. Ошибку 429 по балансу назвать блокировкой живой LLM-проверки.
7. **Доступ и подача · 45 с.** URL/QR только на фактически проверенное приложение с подписью версии. Локальную навигацию не приписывать старому preview. Статус review/merge/main-деплоя взять из [release checklist](RELEASE_CHECKLIST.md), а запись и загрузку видео выполнить с аккаунта команды.
