# Сценарии проверки QalaGo

Таблица объединяет сценарии приёмки и фактически выполненные проверки. Ниже явно отмечены прямые backend-вызовы: они проверяют расчёт, но не заменяют ручную проверку всех экранов и физической доступности объектов. Прогон 19 октября 2026 выполнен через `.venv/Scripts/python.exe` с удалённым из окружения `OPENAI_API_KEY`, подлинным `data/pois.db` на 199 записей и погодными сценариями без сетевых вызовов. Автоматические тесты используют отдельно помеченные синтетические фикстуры; команда и общий результат приводятся в `docs/VERIFICATION.md`.

Перед ручной проверкой запустите `streamlit run app.py` и проверьте sidebar: ненулевое фактическое число POI, дата загрузки, © OpenStreetMap contributors. По умолчанию выбраны ясная **симуляция** и настоящие часы; OpenAI API key не требуется. Каждая карточка — отдельная альтернатива.

## Автоматизация

Основная команда: `python -m pytest -q`. Тесты должны выполняться без сети и без настоящего OpenAI key. Отдельно проверяют геометрию, ETL, ограничения времени и розеток, аэропорт, погоду, LLM fallback и контракт UI/backend. Для повторной сборки подлинного сохранённого снимка: `python -m ingestion.build_database --offline`.

Публичный URL можно считать проверенным только после реального открытия развёрнутого приложения. Локальный запуск, успешный Git push и страница входа Streamlit Cloud этого не подтверждают.
