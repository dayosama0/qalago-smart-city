Таблица объединяет сценарии приёмки и фактически выполненные проверки после аудита. Прямые backend-вызовы проверяют расчёт, но не заменяют ручную проверку всех экранов и физической доступности объектов. Прогон 19 октября 2026 выполнен через `.venv/Scripts/python.exe` без `OPENAI_API_KEY`, с подлинным `data/pois.db` на 199 записей, шестью описаниями и 81 расписанием. Для воспроизводимости ниже используются симулированные часы **19.10.2026, 14:00 UTC+5** и ясная симуляция погоды, кроме отдельно указанных ночи и ветра. Сетевые вызовы не выполнялись. Общий результат тестов и браузерные доказательства — в `docs/VERIFICATION.md`.

Перед ручной проверкой запустите `streamlit run app.py`. Числа, свежесть и атрибуция находятся в боковой панели → «Прозрачность данных». По умолчанию выбраны ясная **симуляция** и настоящие часы; OpenAI API key не требуется. Для повторения таблицы раскройте настройки и задайте указанные часы. ## Автоматизация

`python -m pytest tests/test_ui.py -q` — **10 passed** (фактически выполнено после интеграции источников описаний). Проверены четыре быстрых сценария с настоящим backend, сброс предыдущего строгого фильтра, свёрнутые расширенные настройки и прозрачность, явные ярлыки симуляции, скрытие старых результатов, группировка карточек и предупреждений, второстепенные ссылки 2ГИС, доказательства описаний/часов и сравнение с одним временем и погодой. Ключ и сеть в этих UI-тестах отключены.

Проверки браузера на **390, 430, 768 и 1440 px**, горизонтального скролла и доступности кнопок выполняются отдельно и фиксируются в `docs/VERIFICATION.md`. Наличие адаптивной CSS-разметки или успешный AppTest само по себе не подтверждает мобильную визуальную проверку.

Основная команда: `python -m pytest -q`. Тесты должны выполняться без сети и без настоящего OpenAI key. Отдельно проверяют геометрию, ETL, ограничения времени и розеток, аэропорт, погоду, LLM fallback и контракт UI/backend. Для повторной сборки подлинного сохранённого снимка: `python -m ingestion.build_database --offline`.

Публичный URL можно считать проверенным только после реального открытия развёрнутого приложения. Локальный запуск, успешный Git push и страница входа Streamlit Cloud этого не подтверждают.
